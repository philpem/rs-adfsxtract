# Tools

Developer-side utilities for the golden-image authoring and validation
workflow. Nothing in here ships in the binary; these exist so that real media
and independently-implemented generators can be produced/checked during
development.

## `filecore_build.py` / `filecore.py`

An **independent implementation** of the FileCore/ADFS on-disc format (written
against the authoritative `filecore_guide.md`, not derived from this crate).
`filecore_build.py` builds a single-zone **E-format** (new-map) disc image from
a nested file tree; `filecore.py` is a matching reader. They are retained as:

- a **cross-check oracle** over the Rust reader (two independent
  implementations, so a shared comprehension gap can't silently pass), and
- a **generator** for producing hard-disc/big-directory images and randomised
  fragmentation during authoring.

Limitation: this implementation is single-zone E-format only. Multi-zone
F/G, big-directory and old-map hard discs are generated by the Rust
`testutil` builders instead, and validated against official-tool goldens (see
`GOLDEN_AUTHORING.md`).

## `GOLDEN_AUTHORING.md`

The human-executable recipe for creating real media with the official Acorn
tools (BBC ADFS, RISC OS 4 HForm, RISC OS 2 `!HForm`, DFS) and handing the
captured goldens back for hashing. The donor images those steps copy from are
emitted by:

```sh
ACORNFS_DONOR_OUT=/tmp/donors cargo test --lib emit_golden_donors_if_requested
```
